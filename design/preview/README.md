# Prévia visual local

Abra `index.html` diretamente no navegador e navegue pelas cinco telas locais: salão, mercenários, operações, taverna e inventário. Os arquivos usam apenas CSS e imagens locais; não precisam de servidor, internet ou build. Dados, nomes, preços e ações são ilustrativos.
