# Resumo do pacote

Total: 6 ícones de classe

Classes incluídas:
- Aprendiz (`apprentice`) — Inicial / flexível
- Guerreiro (`warrior`) — Tanque / combate físico
- Ladino (`rogue`) — Crítico / agilidade
- Mago (`mage`) — Dano mágico
- Clérigo (`cleric`) — Suporte / cura
- Arqueiro (`archer`) — Precisão / ataque à distância

Tamanhos: 512x512 master e 128x128 UI.
