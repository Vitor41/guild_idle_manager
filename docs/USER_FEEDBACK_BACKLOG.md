# Melhorias anotadas

## Guias

- **Guia de Classes:** substituir a barra atual pelo índice de seções usado no Guia do Jogo, mantendo a identidade visual e garantindo que cada atalho navegue até a seção correspondente.
- **Guia de Tiers:** corrigir a seção de equipamentos. A progressão de tiers deve conter somente Comum, Incomum, Raro, Épico, Lendário e Mítico, tanto para mercenários quanto para equipamentos. Não exibir T1–T8 como tiers de equipamentos; nível do item é um conceito separado de tier.
