# ML-057 / F34 — submit da busca do Guia

Data: 2026-11-25. Branch `feature/anomalies-ui-audit`. Candidato `2bb187850bf66021c19e0a128c4103560db7a3fa`, base `e59536237899a1aad9d4e82f47d263b6286ceda8`.

## Causa e correção

A DA reproduziu no candidato anterior que o handler local do Guia já chama `preventDefault()`, mas o mesmo evento continuava borbulhando até o handler global de formulários de `main.js`. O listener global então interceptava o GET e substituía o Guia, removendo resultado, mensagem e foco. Isso acontecia para busca encontrada, não encontrada e vazia.

O listener global agora retorna quando `event.defaultPrevented` já está definido. Formulários não consumidos pelo componente continuam no fluxo global. O parâmetro de versão de `main.js` no shell foi incrementado para que o desktop receba a correção.
